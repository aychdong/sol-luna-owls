# 安装与回退 / Install and rollback

当前版为 **v1.1.0（V1 + R4）**。解压安装 ZIP，把 `sol`、`luna` 复制到 `~/.codex/pets/`。Finder 按 ⌘ ⇧ G 前往该目录。

```text
~/.codex/pets/
├── sol/
│   ├── pet.json
│   └── spritesheet.webp
└── luna/
    ├── pet.json
    └── spritesheet.webp
```

替换前先把旧文件夹移到其他目录备份。复制后重新选择宠物；仍显示旧图时完整退出应用再打开。不要复制外层交付目录或素材目录。Sol 与 Luna 需手动切换。

回退可使用 Release 中的 `Sol-Luna-R3-rollback.zip` 或 `Sol-Luna-V1-original-rollback.zip`，按同样步骤替换。旧版素材、历史安装包和试作保存在历史归档中。发布不会自动修改你已安装的宠物。

The current release is **v1.1.0 (V1 + R4)**. Extract the install ZIP, then copy **sol** and **luna** into `~/.codex/pets/` using Finder's ⌘ ⇧ G. Files must be directly inside each pet folder as above.

Back up existing folders elsewhere first. Select the pet again; fully quit and reopen the app if cached artwork remains. Do not copy the outer delivery or source directory. Switch characters manually.

For rollback, use `Sol-Luna-R3-rollback.zip` or `Sol-Luna-V1-original-rollback.zip` from the Release and replace both folders. Publishing does not automatically modify installed pets. Previous assets, packages and trials are preserved in the historical archive.

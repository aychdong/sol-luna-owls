## Sol & Luna · 日月猫头鹰

两只陪你工作的桌面小猫头鹰：Sol 是晨光，Luna 是月夜。

**[下载安装包](https://github.com/aychdong/sol-luna-owls/releases/download/v1.1.0/Sol-Luna-v1.1.0-install.zip)** · [在线试试看](https://aychdong.github.io/sol-luna-owls/) · [一页图解](https://github.com/aychdong/sol-luna-owls/blob/main/media/sol-luna-quick-guide.png)

### 安装（macOS 桌面版）

1. 下载并解压安装包。
2. Finder 按 **⌘ ⇧ G**，将 `sol` 和 `luna` 放入 `~/.codex/pets/`；目录不存在时先创建。替换已有宠物前请先备份。
3. Codex **设置 → 宠物 → 刷新 → 选择 → 唤醒**。

悬停轻跃，拖动跑步，工作时敲电脑。具体动作由应用状态决定，两只需手动选择。[详细说明与 FAQ](https://github.com/aychdong/sol-luna-owls#开始使用)。

只想安装，下载 **install.zip** 即可。**user-preview.html** 是可直接打开的新离线展示页。其他历史与回退附件继续保留，普通使用不需要下载它们。

## English

Meet Sol, your little sunshine owl, and Luna, your moonlight companion.

Download and extract the **install.zip**, then copy **sol** and **luna** into `~/.codex/pets/` in Finder (**⌘ ⇧ G**). Create the folder if missing and back up any existing pets first. Open **Codex Settings → Pets → Refresh → Choose → Wake**.

Hover for a hop, drag to run, and watch your companion type while the app works. Actual animations depend on application state; switch characters manually. [Instructions & FAQ](https://github.com/aychdong/sol-luna-owls#english) · [Live preview](https://aychdong.github.io/sol-luna-owls/).

The install ZIP is all you need. The new **user-preview.html** opens as a standalone offline showcase. Historical and rollback attachments remain available.

This organization updates documentation, previews and the sharing guide. **Pet artwork, the v1.1.0 install ZIP and all original release attachments are unchanged.**

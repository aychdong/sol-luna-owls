Sol & Luna · O Fortuna 猫头鹰桌宠

开始使用，只需复制两个文件夹

1. 打开「可直接安装」，复制 sol 和 luna 两个文件夹。
2. 在 Finder 按 Command + Shift + G，粘贴这个路径并回车：
   ~/.codex/pets/
3. 将两个文件夹粘贴进去。正确结构应是：
   pets/sol/pet.json
   pets/sol/spritesheet.webp
   pets/luna/pet.json
   pets/luna/spritesheet.webp
   不要把外层「可直接安装」一起套进去。
4. 回到 Codex / ChatGPT 桌面应用 → 设置 → 宠物 → 刷新。
   选择「Sol · 晨光」或「Luna · 月夜」，再显示/唤醒宠物。
   也可以在命令菜单选择「显示宠物」，或输入 /pet。
   如果刷新后仍未出现，完全退出桌面应用再打开。

不需要运行脚本，不需要另外下载组件。
Sol 与 Luna 是两个独立宠物，白天/夜间手动切换。
如果已有同名文件夹，先把旧版本移到别处备份，再复制新版本。
以后想停用，选择其他宠物，再把对应文件夹移出 pets 即可。

先看效果
双击「预览/动画预览.html」：可切换动作、大小、速度和浅色/深色背景。
该文件完全离线，可直接在浏览器打开，不依赖临时预览服务器。
「预览/Sol-Luna-设计定稿.png」是大头、圆身、短腿的最终设计稿。
「预览/sol-idle.png」与「luna-idle.png」是安装包中的实际角色帧。

形象与名称
• Sol：白天版，琥珀眼、灰蓝羽毛、金纹披风与太阳主题配饰。
• Luna：夜间版，琥珀眼、深靛蓝羽毛、金纹披风与月亮主题配饰。
• 保留原概念图的大脑袋、短圆身材和短腿，保留挑起的眉羽与表情。
• Sol 是拉丁语表示太阳的阳性名词，与 Luna（月亮）构成日夜组合。

动画内容
待机、向右跑、向左跑、招手、轻跃、受阻后恢复、等待、工作、检视；
另有 16 个观察方向帧。披风、电脑和书本随动作显示。
实际应用控制播放节奏；本地预览为方便检查会持续循环。
系统开启「减少动态效果」时，桌面应用可能只显示静态帧。

核验结果
• 两套 pet.json 与透明无损 WebP 均已生成。
• v2 格式：1536×2288，8列×11行，单格192×208。
• 每套88格均有内容；检查了透明背景、格内边界和无损编码回读。
• 直接运行本机应用的精灵图格式校验函数，两套均被接受。
• 浏览器预览可显示角色与动作控制；未替你选择应用中的宠物。
详见「制作记录/validation.json」与「native-loader-validation.json」。

制作记录
内置 imagegen 生成设计和动作；经用户明确同意，用本地 Python 抠图、对齐、打包。
原始素材、最终提示词、构建脚本均保存在「制作记录」。
这些文件无需复制进 pets。之前圆头无眉羽版及长腿版未用于本次安装包。

English — Quick start

1. Open 可直接安装 (ready-to-install) and copy the sol and luna folders.
2. In macOS Finder press Command + Shift + G and open ~/.codex/pets/. Paste both folders there.
3. Open Settings → Pets → Refresh in the desktop app. Select Sol · 晨光 or Luna · 月夜, then show or wake the pet.

Open 预览/动画预览.html for the offline preview. Use the 中文 / English button to change language.
Back up existing pet folders with the same names. Day/night variants are selected manually.
No scripts are required for installation.

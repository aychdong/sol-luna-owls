# Sol / Luna 最终制作说明

用户最终审美要求优先于之前版本：以最初提供的概念图为比例参考，保留大圆头、短圆身体、几乎被腹羽盖住的短腿；保留灵动琥珀眼、舒展眉羽、披风及金色装饰。日间版重命名为 Sol，夜间仍为 Luna。

原始概念图：用户提供的 O Fortuna 原始概念图。

内置 imagegen 生成定稿与动作图。图像输出没有精确符合桌面尺寸，而且包含画进像素的棋盘格。用户已明确同意使用本地 Python 抠图、逐帧对齐和 WebP 打包。

`build_pets.py` 使用本地 Pillow / NumPy 自动识别11个动作行与每行8个独立角色，去除中性棋盘背景、填充被轮廓包围的白色羽毛区域、修复抗锯齿边缘，并对齐脚底基线。Luna 是同姿态的编辑版本，其白色羽毛区域参考 Sol 腐蚀后的内部轮廓，外边界仍用 Luna 自己的图像。所有原始图保持不变。

统一常态高度约160像素，保留原始绘画比例；跃起帧增加垂直位移。受阻动画从清醒开始、短暂眨眼后恢复。空闲备用格填充中性姿态，避免错误状态出现空白。

动画图是单张透明无损 WebP 精灵图，不是 GIF。播放顺序和帧时长来自本机桌面应用26.901.51231。原生图像加载函数从已安装应用提取后直接执行；两套输出均通过。还用 Pillow 逐像素回读检查了 WebP 无损保存、88格透明区域、格内边界与有效内容。

独立 HTML 预览直接嵌入安装包的精灵图，完全离线。预览中的重复循环便于检查，桌面应用多数动作会重复三轮后转回待机。

验证边界：未在原生应用中实际选择或更换用户宠物。工具层禁止自动操作该应用，因此本次证据是原生格式函数接受、图像检查及浏览器预览。所有最终安装步骤在使用说明中。

日间/夜间是两套外观，应用不会自动按时间切换。安装目录名为 sol 与 luna。

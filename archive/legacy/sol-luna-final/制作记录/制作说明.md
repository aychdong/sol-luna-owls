# 制作记录 / Production notes · 2026-09-15

用户审阅四张概念图后确定：Sol 待机结合好奇与整理披风，Luna 整理披风后打盹；工作动画保留电脑；受挫时避免撑穿披风。最终飞翔试作仍有翅根与披风遮挡跳变，按用户明确指示回退到原版跑步。

After concept review, Sol combines curiosity and cape care; Luna combines cape care and a nap. Work keeps the laptop visible; setback avoids raised wings through the cape. Flight trials still had inconsistent occlusion and were replaced with the original running under the user's fallback instruction.

`build_pets.py` 按明确网格与角色区域识别主体，将邻近问号、星点、z 独立组件关联到各帧。原图包含假棋盘背景，因此用颜色与外部填充抠图，保留被羽毛轮廓包围的象牙白区域；电脑素材单独保留低饱和灰蓝屏幕。组内统一比例与脚底基线，电脑用右边缘定位。原始文件不修改。

The builder extracts known grid regions, associates detached effects, removes painted checkerboards, preserves enclosed ivory plumage and low-chroma laptop lids, and uses one scale per sequence. Standing feet and laptop edges are anchored. Generated originals remain unchanged.

安装精灵图保持 v2 的 1536 × 2288 无损 RGBA WebP。备用格使用待机首帧，避免空白。原版跑步不镜像、不重绘，逐像素保持一致。思考仅占工作六帧中的部分姿势，不能独立根据模型思考阶段触发。

Native v2 sheets use 1536 × 2288 lossless RGBA WebP. Spare cells contain the idle first frame. Running is preserved pixel-for-pixel without mirroring. Thinking occupies part of the six-frame work cycle; the native app cannot independently follow model reasoning phases.

`validation.json` 记录每帧边界与定位；`quality-checks.json` 核对运行内容与回退像素；`native-loader-validation.json` 记录本机图像格式函数的结果。原生宠物界面的选择、状态触发及连续播放未人工验证。浏览器 UI 渲染未自动验证，网页脚本通过语法与行为检查；不要把这些记录解读为原生 UI 测试。

Reports cover extraction, pixel checks and native image-format acceptance. Native pet selection, state triggers and live playback were not manually exercised. Browser rendering was not automatically verified; script syntax and behavior were checked separately. These records are not native UI integration tests.
